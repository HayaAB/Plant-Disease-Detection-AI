# Plant Disease Detection AI

This project is a computer vision web application that detects plant diseases from leaf images using a trained deep learning model.

## Features
- Upload leaf image
- Predict plant disease
- Show confidence score
- Display top 3 predictions
- Provide basic care recommendation

## Technologies
- Python
- TensorFlow
- MobileNetV2
- Gradio
- Kaggle Dataset

## Model
The model was trained using transfer learning with MobileNetV2 on 23 plant disease classes.
